# projects-page

A **static portfolio site** built with **HTML and CSS only**, designed around **hexagonal geometry** and **neutral gray tones** by **AI**.

---

**Pure static site**
  - No JavaScript framework
  - No build step
  - No dependencies

**Hexagon-based visual language**
  - Consistent geometry across layout and accents
  - Subtle technical line patterns

**Serious grayscale aesthetic**
  - Dark UI with neutral gray tones
  - No strong colors, distractions, or visual noise
  - Professional and readable

**Easy project management**
  - Each project is a **single repeated HTML block**
  - Add, remove, or reorder projects by copy/paste
  - No configuration files required

**Responsive**
  - Desktop → tablet → mobile
  - Projects grid collapses cleanly to single column
